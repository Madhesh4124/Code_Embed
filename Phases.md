### Tasks

#### 4.1 Dual Encoder
```python
# model/dual_encoder.py
class DualEncoder(nn.Module):
    def __init__(self, config):
        self.code_encoder = Encoder(config.code_encoder)
        self.text_encoder = Encoder(config.text_encoder)
        # Total params ≈ 8M (each ~4M)
    def forward(self, code_ids, code_mask, text_ids, text_mask):
        z_code = self.code_encoder(code_ids, code_mask)
        z_text = self.text_encoder(text_ids, text_mask)
        return z_code, z_text
```

## Risk Mitigation

| Risk | Likelihood | Impact | Mitigation |
|------|------------|--------|------------|
| Custom model << BM25 | Medium | High | Start with BM25; if neural fails, document why |
| Training unstable (NaN) | Medium | Medium | Gradient clipping, lower LR, Pre-LN, fp32 master weights |
| OOM on GPU | High | Medium | Gradient accumulation, smaller batch, gradient checkpointing |
| CodeSearchNet download fails | Low | High | Mirror dataset, use local cache |
| Hard negatives don't help | Medium | Low | Expected; document as negative result |
| Pretrained >> custom (large gap) | High | Low | This is expected; frame as research question answer |
